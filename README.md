# Автоматизация груминг-салона на 1С

Конфигурация на платформе **«1С:Предприятие 8.3»** для автоматизации работы груминг-салона: предварительной записи клиентов, продажи товаров и услуг, складского учёта и расчёта себестоимости.

Проект разработан в рамках программы «Разработчик 1С расширенный» Яндекс Практикума и дипломной работы.

## Реализованные возможности

### Предварительная запись

- Запись клиентов на услуги.
- Расчёт времени окончания записи с учётом продолжительности услуг.

### Продажа товаров и оказание услуг

- Документ `РеализацияТоваровИУслуг` для оформления операций салона.
- Алгоритмы проведения документов и формирования движений по регистрам.
- Печатная форма документа реализации.

### Складской учёт и себестоимость

- Списание товаров при реализации.
- Расчёт себестоимости по средней стоимости.
- Учёт остатков товаров, продаж, затрат и заказов клиентов.

### Регистрация клиентов и бизнес-процессы

- Работа со справочниками пользователей и контрагентов.
- Бизнес-процесс `ДорегистрацияКлиента`.
- Учёт признака необходимости дорегистрации.

### HTTP-сервис

- HTTP-сервис работы с пользователями.

### Отчётность

- Внешний отчёт «Исполнение заказов клиентов».
- Подключение отчёта через механизмы Библиотеки стандартных подсистем (БСП).

## Результаты

Разработана конфигурация, объединяющая основные операции груминг-салона:

- предварительную запись клиентов;
- оформление продажи товаров и оказания услуг;
- списание товаров и расчёт себестоимости;
- учёт продаж и затрат;
- получение отчётности по исполнению заказов.

Дополнительно реализованы печатная форма, бизнес-процесс дорегистрации клиента и HTTP-сервис работы с пользователями.

## Выводы

Проект демонстрирует реализацию связанных механизмов 1С: от ввода данных в управляемых формах до проведения документов и формирования отчётности.

Разделение данных между документами и регистрами позволяет использовать одни и те же хозяйственные операции для складского учёта, расчёта себестоимости и анализа продаж.

## Системные требования

- Установленная платформа **«1С:Предприятие 8.3»**.
- Доступ к режимам **«Конфигуратор»** и **«1С:Предприятие»**.
- Операционная система, поддерживаемая установленным выпуском платформы.
- Отдельная информационная база для загрузки проекта.

Для проверки HTTP-сервиса дополнительно необходимы совместимый веб-сервер и публикация информационной базы с включённым HTTP-сервисом.

> Точный выпуск платформы, на котором проверен проект, пока не указан. Совместимость со всеми выпусками 8.3 не подтверждена.

## Развёртывание

Выберите способ, соответствующий опубликованному формату проекта.

### Из выгрузки информационной базы `.dt`

1. Скачайте файл выгрузки `.dt`.
2. Создайте новую пустую информационную базу.
3. Откройте её в режиме **«Конфигуратор»**.
4. Выберите **Администрирование → Загрузить информационную базу**.
5. Укажите файл `.dt` и дождитесь завершения загрузки.
6. Запустите базу в режиме **«1С:Предприятие»**.

> Загрузка `.dt` заменяет содержимое выбранной базы. Используйте отдельную пустую базу.

### Из исходников конфигурации

1. Скачайте репозиторий и распакуйте архив.
2. Создайте новую пустую информационную базу.
3. Откройте её в режиме **«Конфигуратор»**.
4. Выберите **Конфигурация → Открыть конфигурацию**.
5. Выполните **Конфигурация → Загрузить конфигурацию из файлов**.
6. Укажите каталог с исходниками конфигурации.
7. Выполните **Конфигурация → Обновить конфигурацию базы данных**.
8. Запустите базу в режиме **«1С:Предприятие»**.

Исходники конфигурации не содержат пользовательские данные. Перед проверкой операций заполните необходимые справочники и исходные документы.

Внешние отчёты, опубликованные отдельными файлами, подключаются отдельно.

## Проверка работы

1. Создайте предварительную запись и проверьте расчёт времени окончания услуг.
2. Оформите реализацию товаров и услуг при наличии необходимых исходных данных.
3. Проверьте движения проведённого документа.
4. Сформируйте печатную форму реализации.
5. Откройте отчёт «Исполнение заказов клиентов», если он подключён в базе.
