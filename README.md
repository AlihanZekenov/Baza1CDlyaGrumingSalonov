Автоматизация груминг-салона на 1С
Проект на платформе «1С:Предприятие 8.3».

Конфигурация предназначена для автоматизации работы груминг-салона: предварительной записи клиентов, оформления продажи товаров и оказания услуг, а также учёта хозяйственных операций.
Реализованные возможности
Предварительная запись
- Документ предварительной записи клиентов на услуги.
- Расчёт времени окончания записи с учётом продолжительности услуг.
Продажа товаров и оказание услуг
- Документ РеализацияТоваровИУслуг для оформления операций салона.
- Работа со справочниками, документами и регистрами конфигурации.
- Формирование печатной формы документа реализации.
Регистрация клиентов и бизнес-процессы
- Работа со справочниками пользователей и контрагентов.
- Бизнес-процесс ДорегистрацияКлиента для завершения регистрации.
- Учёт признака необходимости дорегистрации.
HTTP-сервис
- Реализация HTTP-сервиса работы с пользователями.
- Обработчик по пути /hs/users/getUser.
Отчётность
- Внешний отчёт «Исполнение заказов клиентов».
- Подключение внешнего отчёта с использованием механизмов Библиотеки стандартных подсистем (БСП).

Что демонстрирует проект
- Разработку объектов конфигурации и связей между ними.
- Написание прикладной логики на встроенном языке 1С.
- Автоматизацию записи клиентов и оформления продаж.
- Создание печатных форм и внешних отчётов.
- Использование бизнес-процессов и HTTP-сервисов.
Запуск
Для работы необходима установленная платформа «1С:Предприятие 8.3». Способ загрузки зависит от опубликованного формата проекта.
Из выгрузки информационной базы .dt
1. Скачайте файл выгрузки информационной базы.
2. Создайте новую пустую информационную базу и откройте её в Конфигураторе.
3. Выберите Администрирование → Загрузить информационную базу.
4. Укажите скачанный файл .dt и дождитесь завершения загрузки.
5. Запустите базу в режиме 1С:Предприятие.
Загрузка .dt заменяет содержимое выбранной базы. Используйте отдельную базу для знакомства с проектом.
